# Source and art provenance

> **TL;DR:** This began as Jess Maddox's personal AI-assisted number-learning game. The complete teaching design is retained, with fresh fictional examples and local configuration replacing personal constants.

The public repository begins with an explicit extraction of the original HTML, CSS, application and pure logic. The original personal data module and its tests were not copied. All public fixtures were written independently. Nova, Orion and Comet are invented demonstration learners; example phone numbers use the [NANPA-reserved fictional 555-0100 through 555-0199 range](https://nanpa.com/numbering/555-line-numbers) and library/example codes are invented strings.

The original visual style is preserved. Baloo 2 is an unmodified variable font from the official Google Fonts repository, with its exact pinned source URL and SHA256 in `public/fonts/SOURCES.json` and full SIL OFL notice alongside it. esbuild 0.28.2 is the pinned MIT-licensed build tool. No runtime third-party service is required. Emoji use the viewer's platform rendering.

`remember-your-numbers-hero.png` is a new fictional ChatGPT illustration created without reference images or personal likenesses. It is marketing art, not a screenshot. The prompt requested a warm cream-paper learning workshop in coral, teal and violet, rounded exact product lettering, individual number tiles 0–5, a star path, a tiny rocket and planet, and no people, real names, phone/account numbers, brands or personal information. `learning.png` is a screenshot of the actual game with the invented Comet learner and example code 001728.
