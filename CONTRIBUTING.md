# Contributing

Bug reports, ideas and code changes are welcome. This began as a personal project; there is no support schedule or response-time promise.

Describe what you expected and what happened, including browser/device and reproducible steps. Use invented numbers and learners. Do not attach a personal backup, phone number, school identifier, screenshot with real data, or browser storage export.

For changes, run the core and browser checks described in docs/verification.md. Preserve the full learning ladder, local setup/export path, default-silent speech and coordinated storage guards. Add a regression test when fixing a behavior bug. General improvements belong in this public engine so hosted copies can update to a reviewed release.
